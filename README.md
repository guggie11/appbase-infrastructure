# Appbase Infrastructure

Repository koordinasi lintas-repo untuk project **Appbase** — App Template (boilerplate)
yang aman secara default, type-safe end-to-end (OpenAPI + Orval), dan siap dipakai
sebagai fondasi project internal baru.

## Repositories
- [`appbase-frontend`](https://github.com/guggie11/appbase-frontend) — React 19 + TypeScript + Vite + Tailwind v4
- [`appbase-backend`](https://github.com/guggie11/appbase-backend) — FastAPI + SQLAlchemy 2.x + PostgreSQL
- `appbase-infrastructure` (repo ini) — Docker Compose, CI/CD lintas repo, dokumentasi SSOT

## Dokumentasi
- [`docs/PRD.md`](docs/PRD.md) — Product Requirements Document (SSOT produk)
- [`docs/CHANGELOG.md`](docs/CHANGELOG.md) — riwayat keputusan & perubahan
- `docs/adr/` — Architecture Decision Records
